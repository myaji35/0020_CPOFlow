# UI 언어 변경 기능 진단 (ISS-299)

> 작성일: 2026-05-01 | 담당: biz-validator/i18n-audit | 방식: 읽기 전용

---

## 1. 인프라 구현 상태

| 항목 | 상태 | 근거 |
|------|------|------|
| `users.locale` 컬럼 | ✅ 존재 | `User::LOCALES = %w[en ko ar]` + validates inclusion |
| `User#preferred_locale` | ✅ 존재 | `locale.presence \|\| "en"` (기본값: en) |
| `ApplicationController#set_locale` | ✅ 구현됨 | `before_action :set_locale` → `I18n.locale = current_user.preferred_locale.to_sym` |
| 비로그인 fallback | ✅ 구현됨 | Accept-Language 헤더 → `:ko` 기본값 |
| `PATCH /settings/locale` 라우트 | ✅ 존재 | `settings_update_locale PATCH /settings/locale` |
| `Settings::ProfileController#update_locale` | ✅ 구현됨 | `User::LOCALES.include?(locale)` 검증 후 `current_user.update!(locale:)` |
| 설정 화면 UI | ✅ 노출됨 | `settings/base/index.html.erb` 247~274행: 한국어/English/العربية 버튼 3개 |
| 지원 locale 수 | 3개 | ko, en, ar |

**인프라는 완전히 구현되어 있다.** 라우트→컨트롤러→DB 저장→다음 요청 locale 적용까지 파이프라인 정상.

## 2. 설정 화면 노출 여부

`app/views/settings/base/index.html.erb` 247~274행에 **"환경설정" 섹션**이 존재하며:
- 언어 선택 버튼 3개 (`button_to settings_update_locale_path, method: :patch, params: { locale: code }`)
- 현재 선택된 locale이 `bg-primary text-white`로 강조 표시
- 다크모드 테마 선택(3개)도 동일 섹션에 포함

언어 변경 UI는 정상 노출됨.

## 5. 사용자 영향 (locale → en 변경 시 실제 변경 비율)

| 영역 | locale 변경 후 동작 | 비율 |
|------|-------------------|------|
| Devise 로그인/로그아웃 flash | ✅ 영어 (en.yml devise 섹션 완비) | 100% |
| 성공/실패 flash 메시지 (notice/alert) | ⚠️ **부분 영어** | ~33% |
| ERB 본문 UI 텍스트 (버튼, 레이블, 헤더 등) | ❌ 한글 고정 (하드코딩) | 0% |
| ActiveRecord validation 에러 | ❌ 한글 고정 (`errors.messages` en.yml 미완) | 0% |
| `time_ago_in_words` 등 Rails 헬퍼 | ⚠️ Rails 기본 영어 (locale 파일 미연결) | Rails 내장값 |
| 설정 화면 자체 레이블 | ❌ 한글 하드코딩 ("언어/Language", "테마/Theme") | 0% |

### Flash 메시지 상세
- 전체 notice/alert: **141개**
- `t()` 사용 (locale 반영): **46개 (32.6%)**
- 한글 하드코딩 (locale 무시): **95개 (67.4%)**

**결론: locale을 en으로 변경해도 UI의 약 5% 미만만 실제로 영어로 변환됨.**

## 6. 결론: 현재 상태로 사용 가능 여부

### "i18n 기능 동작 여부"
- **locale 저장/불러오기 기계**: ✅ 완전 동작
- **실제 UI 다국어 효과**: ❌ **사실상 미동작**

### 현황 요약
> 인프라(DB 컬럼, 컨트롤러, 라우트, 설정 UI)는 100% 완성되어 있으나,
> ERB 본문의 97.8%가 i18n 미적용 한글 하드코딩 상태.
> locale을 en/ar로 변경해도 Devise 시스템 메시지와 일부 Flash 메시지(33%)만 번역되며,
> 칸반, 대시보드, 폼, 레이아웃 등 핵심 화면은 한글로 고정.

**현재 상태로는 "다국어 지원 앱"으로 볼 수 없음. 인프라 Only, 콘텐츠 미번역.**
