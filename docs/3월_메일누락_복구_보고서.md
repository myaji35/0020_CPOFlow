## 2. 누락 원인

### 근본 원인: Anthropic API 크레딧 고갈

CPOFlow의 이메일 동기화 파이프라인은 다음 순서로 작동합니다:

```
Gmail API → 메일 수신 → LLM(Claude Haiku) 판정 → RFQ 여부 결정 → Order 생성
```

**2026-03-07 시점 Anthropic API 크레딧이 소진**되면서:

1. LLM 호출이 실패 (`credit balance is too low`)
2. 키워드 전용 판정으로 폴백
3. 키워드 판정의 낮은 정확도(10.7%)로 대부분의 RFQ 메일이 `excluded` 처리
4. Order 미생성 → 칸반 보드에 미등록

### 부수 원인

| 원인 | 영향 |
|------|------|
| 키워드 전용 판정의 변환율 10.7% (정상 25.3%) | RFQ 메일 절반 이상 누락 |
| 백필 시 날짜 범위 미지정 | 최근 500건만 조회되어 과거 메일 미포함 |
| `source_email_id` 멱등성 | 동일 메일 재처리 시 기존 excluded 판정 유지 |
