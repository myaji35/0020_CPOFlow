CPOFlow 시작하기

3분 안에 핵심을 이해하세요 — 조달/발주 9단계 워크플로

1첫 3단계 체크리스트

대시보드 상단 "시작하기" 카드에서 3단계를 순차 진행합니다.

Step 1 — Gmail 연결

  • 설정 → 이메일 계정 → Gmail 연결하기 클릭
  • OAuth 동의 후 15분마다 RFQ 메일 자동 수집
  • 토큰 만료 시 대시보드 상단에 빨간 배너 노출 → 다시 연결 클릭

Step 2 — 첫 발주 만들기

  • 메일에서 자동 변환: Inbox "견적성 메일" 탭 → 후보 → "칸반으로 이동"
  • 수동 생성: 대시보드 → 신규 발주 버튼

Step 3 — 담당자 배정 받기

  • 칸반 카드/드로어에서 "담당자 추가" 클릭 → 직원 선택
  • 매니저 일괄 배정: 대시보드 상단 "팀 과부하 TOP 3" 카드 → 드릴다운
